ZEE CON WEBSITE — HTML, CSS & JAVASCRIPT

HOW TO RUN
1. Extract this ZIP file.
2. Open the zee_con folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

The page structure, typography, section order, green/neutral palette, cards and responsive behavior were recreated from the Figma design context. The mobile navigation menu and footer year are handled by script.js.

IMAGE NOTE
The original Figma image assets could not be copied into this ZIP because the Figma asset host was unreachable from the file runtime. The image areas currently use CSS gradient placeholders. Export the corresponding images from Figma into the images folder, then replace the gradient background-image declarations in style.css with local paths.
